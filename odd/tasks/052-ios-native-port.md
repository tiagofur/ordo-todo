# ODD 052 — Port iOS nativo SwiftUI (Liquid Glass)

> Estado: EN CURSO — T1 scaffold
> Fecha: 2026-11-13 · Owner: sesión actual

## Header

- Objective: port Android nativo a iOS nativo SwiftUI con HIG + Liquid Glass, misma v1 que Android.
- Branch: `odd/052-ios-native-port` (una rama; slices por tarea).
- Delivery strategy: ask-on-risk (default). Forecast: ~1200 líneas autoría (scaffold + shell + 5 pantallas + cliente API). Slices: T1 scaffold, T2 shell+Hoy, T3 resto.
- Test runner: `xcodebuild test` (XCTest/Swift Testing) + `swift test` si hay package; UI se verifica en Simulator.

## Specs

- S1 — "reproducir la app Android para iOS". Alcance: paridad v1 Android (Auth, Hoy, Tareas, Hábitos, Captura, Detalle, Foco, Ajustes, notificaciones locales, offline). Backend: mismo NestJS `/api/v1`, sin backend nuevo. Checks: cliente Swift contra `/tasks/today`, `/habits/today`, `/timers/*`, `/auth/*`; outbox offline como Android.
- S2 — "diseño NATIVO IOS para que todo este perfectamente integrado al sistema apple en diseño y funcionalidad". Alcance: HIG, nada de piel M3. Componentes: `TabView`, `NavigationStack`, `List` inset-grouped, `Form` agrupado, SF Symbols, Dynamic Type, claro/oscuro sistema. Anti: FAB, Checkbox cuadrado, NavigationBar M3, vidrio a mano en contenido. Checks: revisión impeccable `ios.md`, capturas claro/oscuro + texto grande.
- S3 — "imprecindible usar las ultimas diretrices de Liquid Glass". Alcance: Xcode 26 SDK, iOS 26+. Reglas: componentes nativos adoptan glass automático; glass solo en navegación/control flotante, nunca en filas/cards; no apilar glass; tint solo acción principal; concentricidad de radios; custom solo `.glassEffect` + `GlassEffectContainer`; respetar Reduce Transparency/Contrast/Motion. Checks: sin fondos opacos propios en bars, scroll edge effect visible.
- S4 — "localizacion de busqueda". Alcance: `.searchable` con `placement:.automatic` (iPhone abajo, iPad top-trailing); `Tab(role:.search)` si búsqueda es destino top-level; `.searchSuggestions` + scope bar/tokens + estado vacío. Checks: búsqueda filtra Hoy/Tareas, accesible a una mano.
- S5 — "al hacer scroll se 'encoje' el boton nav bar". Alcance: `TabView { }.tabBarMinimizeBehavior(.onScrollDown)` (cápsula encoge al bajar, reaparece al subir); large title 34pt Bold colapsa a inline 17pt; toolbar con scroll edge blur+fade automático; `tabViewBottomAccessory` solo si aporta (mini-player Hoy). Checks: scroll down encoge, scroll up restaura, contenido pasa por debajo con blur.
- S6 — "todo que sugiere y HACE apple en sus apps". Alcance: tabs solo navegación (2-4: Hoy·Tareas·Hábitos·Ajustes + Search), `+` en toolbar → sheet; swipe inicio completar / fin posponer-eliminar + menú contextual + preview; completar = háptica + tachado, re-tap deshace; sheets, pull-to-refresh, `swipe-back` borde; Live Activity + WidgetKit + AlarmKit/time-sensitive para foco; App Intents/Siri, Centro de Control, share extension; Keychain en vez de Keystore; i18n EN/ES/PT-BR vía `.xcstrings` desde `packages/native-codegen` (namespace Native). Fuera v1 (PRODUCT.md): Kanban, OKRs, reports, reuniones, notas, workspaces, coach IA. Riesgo abierto: Sign in with Apple 4.8 (sin proveedor backend) + `DELETE /users/me` expuesto (verificar) → 4.8/5.1.1.
