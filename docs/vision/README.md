## Cómo usar esta carpeta

- **Humanos**: leer en el orden del índice. `product-vision.md` primero.
- **Agentes (Gentle-AI)**: esta carpeta es contexto, no spec ejecutable. El trabajo ejecutable vive en [`odd/tasks/`](../../odd/tasks/) con specs `S#` autoritativas y en [`docs/planning/roadmap.md`](../planning/roadmap.md). No infieras tareas desde aquí: si algo no tiene ODD doc, no está aprobado para implementar.
- **Regla**: ningún documento nuevo puede prometer algo que contradiga `promises-audit.md` sin corregir primero la superficie donde se promete.
